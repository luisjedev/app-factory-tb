Modelo mental

La app posee el adaptador; UI posee la fuente.

@repo/ui exporta TSX con StyleX. Cada app debe transformar esas llamadas y emitir el CSS usando la integración apropiada para su build.

Semáforo de decisión

EstadoCondiciónAcción
VerdeReact/TSX, monorepo privado, adaptador oficialAdoptar y automatizar builds.

RojoCero Babel, cero configuración por app o CSS arbitrariamente dinámicoNo basar todo el sistema en StyleX.

Checklist de mantenimiento

  • Mantener alineadas las versiones de runtime, Babel, PostCSS, unplugin y ESLint de StyleX.
  • Al añadir una app, instalar y configurar su adaptador; no copiar el de otra tecnología.
  • Al mover fuentes, revisar include, exclusiones y externalPackages.
  • Ejecutar lint, tipos y build de todas las apps después de actualizar StyleX o el bundler.
  • Probar al menos un componente, variables, tema alternativo, producción y HMR.
  • Inspeccionar que no llegue un stylex.create() inesperado al runtime y que exista CSS atómico.
