StyleX: del TSX al CSS

Mapa de responsabilidades, ubicación de dependencias y diagnóstico de la integración real de app-factory-tb.

La frase que organiza todo

La app produce el artefacto final, por eso la app configura los compiladores.

@repo/ui declara estilos y sus dependencias de ejecución; cada app Next.js transforma ese código y reúne su CSS.

Los cinco actores

ActorEntradaResponsabilidadNo hace
StyleXObjetos JSAPI para declarar estilos atómicos.No coordina por sí solo el build.
BabelJS/TS/TSXParsea un AST y ejecuta el plugin que precompila llamadas StyleX.No construye el CSS global final.
PostCSSCSS + archivos incluidosEjecuta el plugin que recopila reglas y sustituye @stylex.No empaqueta React ni rutas.
Next.js/TurbopackLa app completaDescubre configs, compila módulos, procesa CSS y crea bundles.No coordina todos los paquetes del repo.
TurborepoScripts y grafo de paquetesOrdena, paraleliza y cachea tareas como build.No transforma stylex.create().

El plugin de PostCSS vuelve a utilizar la configuración del plugin Babel para interpretar los mismos archivos y extraer las mismas reglas. Por eso postcss.config.js importa babel.config.js.

Estado actual: `packages/ui` contiene también los plugins Babel y PostCSS. No rompe nada, pero son redundantes mientras UI exporte fuente y sean las apps quienes la compilen. Serían necesarios allí si UI adquiriera su propio proceso de compilación/extracción.

Para qué sirve cada línea clave

ConfiguraciónEfecto
presets: ["next/babel"]Conserva las transformaciones Babel esperadas por Next al añadir una configuración personalizada.
runtimeInjection: falseEvita inyectar CSS mediante JavaScript; obliga a generar CSS estático con PostCSS.
include: ["app/**", "../../packages/ui/src/**"]Indica dónde buscar todas las declaraciones StyleX que deben contribuir al CSS.
babelrc: false dentro de PostCSSHace explícita la invocación interna de Babel de PostCSS y evita cargar otra config implícitamente.
plugins: babelConfig.pluginsGarantiza que compilación JS y extracción CSS usan las mismas opciones de StyleX.
@stylex;Es el marcador que PostCSS reemplaza por las reglas atómicas generadas.
import "./globals.css"Introduce esa hoja final en el grafo de todas las rutas desde el layout raíz.

Cómo descubre Next las configuraciones

El nombre del archivo es una API por convención.

next build toma la carpeta de la app como raíz, busca nombres conocidos como babel.config.js y postcss.config.js, evalúa sus exports y conecta sus plugins a la etapa correspondiente. Node y Turborepo no hacen este descubrimiento.
