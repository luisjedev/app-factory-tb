# La misión incluye evaluar StyleX entre Next.js y Vite

El objetivo ya no es solo comprender la integración Next.js existente: el usuario quiere decidir si StyleX puede sostener un sistema visual compartido y mantenible entre paquetes fuente y apps React con distintos builds. Esto exige que las siguientes lecciones evalúen compatibilidad con pruebas reales y separen compilador, adaptador, bundler y orquestador.
