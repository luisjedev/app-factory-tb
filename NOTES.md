# Teaching notes

- Enseñar en español.
- Usar el repositorio real como caso de estudio y conectar cada concepto con un archivo concreto.
- El usuario quiere comprender mecanismos internos y ubicación de dependencias, no solo recetas.
- Favorecer diagramas de pipeline, tablas de responsabilidad y diagnóstico por síntomas.
- La decisión final buscada es si StyleX puede ser la base mantenible del sistema visual entre apps Next.js y Vite React.
- Distinguir siempre compilador, adaptador, bundler y orquestador; “unplugin” no debe presentarse como Babel-free.
